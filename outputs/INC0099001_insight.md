## 📝 Incident Summary

API gateway cluster experienced an outage due to a memory leak in a new logging middleware that was introduced in deployment CHG0010045. The large batch job payloads generated at 02:00 UTC exacerbated the issue.

---

## 🔎 Root Cause Analysis

Confirmed root cause: unbounded memory buffering in new logging middleware combined with unusually large batch job payloads.

---

## 🛡️ Prevention Measures

- Ensure all middleware changes are load tested with production-scale payloads before deployment.

---

## ✅ Resolution Recommendations

- Update the middleware to stream request bodies instead of buffering in memory, with a hard cap of 64KB for logging purposes.
- Enforce batch job payload limits.

---

## 🤖 Automation & Monitoring Suggestions

- Configure memory utilization alerts at 70% and 85% thresholds.
